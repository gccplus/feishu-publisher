# 常见问题

**为什么所有者显示应用名？**
本版以自建应用身份发布，所有者是应用；配置的协作者会获得可管理权限。没有以个人账号登录发布的功能。

**改版本号会换链接吗？**
默认发布不会。首次创建主文档后一直复用 feishu_url；新版本保存为该文档的飞书原生命名版本。

**为什么同版本快照没有变？**
命名版本是保存当时的快照。后续同版本修改只更新主文档；改 version 后可保存新的快照。

**还需要 feishu_published_version 吗？**
不需要。0.1.17 从飞书读取版本列表，成功后自动移除旧属性。日常维护 version 即可，feishu_url 由插件维护。

**能回退吗？**
插件没有一键回退。可在飞书历史记录中查看和还原内容；还原不会修改本地笔记，再次发布仍会用本地正文覆盖。

**为什么没有互联网分享？**
需要显式开启分享、应用具备对应权限，并符合租户策略。可管理协作者与互联网访客是不同权限范围。

**显示版本保存未确认？**
飞书版本创建是异步操作。插件会保留主链接及待完成版本信息，下次先查询原请求。若网络中断且未取得版本标识，请先到飞书核对已存版本；确认确实没有后，再清理 feishu_pending_snapshot 重试。

**支持腾讯文档、移动端或自动同步吗？**
当前公开版本仅支持 Obsidian 桌面端手动发布到飞书，没有双向同步或后台自动发布。

**遇到错误如何反馈？**
在仓库 Issues 中附上插件版本、Obsidian 版本、操作步骤、已脱敏的提示和最小示例。不要提供 App Secret、访问令牌、敏感正文或私人图片。
