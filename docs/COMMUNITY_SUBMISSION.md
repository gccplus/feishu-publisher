提交步骤：

1. GitHub 公开仓库默认分支包含源码、README、LICENSE、manifest.json、锁文件和构建脚本。
2. 确认 tag 为 `0.1.18` 的 GitHub Release 已发布，附件包含 main.js 和 manifest.json。
3. 打开 https://community.obsidian.md 并登录 Obsidian 账号；在设置中关联 GitHub 账号。
4. 添加插件，填入实际公开仓库链接，检查目录扫描结果。
5. 完成扫描提示的修正后发布目录条目。GitHub Release 发布成功并不等于社区目录已经上架。

账号登录、验证码和关联确认必须由账号本人完成。提交时不能把测试覆盖说成真实飞书租户验收，也不能宣传尚未支持的双向同步、个人账号登录或移动端能力。

官方流程：https://docs.obsidian.md/Plugins/Releasing/Submit%20your%20plugin
