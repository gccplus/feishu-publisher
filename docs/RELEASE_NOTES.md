初始公开版本：将 Obsidian 笔记手动发布到飞书，并使用同一主链接维护正文和原生命名版本。

- Markdown 原生块、Callout 提示卡片、Mermaid 文本绘图。
- 仓库内图片和公开网络图片自动上传。
- version 改变时保存原生命名版本，日常更新主链接不变。
- 协作者可管理权限；按需互联网只读分享。
- 修复默认标题 Callout 缺失标题映射的问题。

安装：下载 main.js 和 manifest.json，放入 `.obsidian/plugins/feishu-publisher/` 后启用；也可解压 ZIP 安装。升级时保留 data.json。

需要 Obsidian 桌面版 1.11.4+，以及用户自己的飞书自建应用。必须配置创建、读写、转换、素材上传、协作者及 `drive:drive:version` 权限。完整说明见仓库 README。

更新会用本地正文覆盖远端正文。没有双向同步、个人账号 OAuth 登录或插件内一键回退。

测试为本地自动测试和模拟发布流程，未在本次发布中验证真实飞书租户的全部权限、版本保存和页面渲染。建议先使用测试笔记验收。
